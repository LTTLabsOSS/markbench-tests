# Recording Session

Use **Recording Session** in the **Utility** category to capture the system metrics that MarkBench supports on your platform.

1. Start **Recording Session** in MarkBench.
2. Click **Stop** in the recording window to end the capture.

Closing the recording window also ends the capture. MarkBench saves the run.

The utility needs a Windows or Linux desktop session and a Python installation with Tk support.
On Linux, Tk needs an X11 display.

## Dummy recording harness

The `dummy.py` script waits for a socket connection during an ad hoc recording session.
